A web interface for the Python + OpenCV project. Your browser camera streams frames to the Python server, which runs adaptive skin segmentation and 68-point facial landmarks; this page controls it.

How it works

Image operations prepare each frame (grayscale, equalization, blur, colour conversion). Segmentation learns each person's skin colour and measures how much skin remains on the nose, mouth and chin. Facial landmarks locate those three zones. The status is a majority vote over the last 9 frames.
